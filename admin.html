ADMIN EXAM CODE STUDIO

Create an examination from HTML

Write the exam HTML yourself, paste it below, validate the extracted questions, then publish. Pasted scripts and styles are never executed.

HTML format guide

Root: data-qco-exam with data-title, data-description, data-duration (minutes), and data-total-marks.

Each question uses data-question, data-correct (0–3 or A–D), optional data-marks, a heading, and four data-option elements.

<div data-qco-exam data-title="General Knowledge Test" data-description="QCO examination" data-duration="20" data-total-marks="2">
  <section data-question data-correct="1" data-marks="1">
    <h3>বাংলাদেশের রাজধানী কোনটি?</h3>
    <div data-option>চট্টগ্রাম</div><div data-option>ঢাকা</div>
    <div data-option>রাজশাহী</div><div data-option>খুলনা</div>
  </section>
  <section data-question data-correct="0" data-marks="1">
    <h3>2 + 2 কত?</h3>
    <div data-option>4</div><div data-option>3</div>
    <div data-option>5</div><div data-option>6</div>
  </section>
</div>
