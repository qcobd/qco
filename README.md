# QCO — Quiz Competition Organization

Official website: https://qcobd.github.io/qco/

## Project
A responsive quiz competition platform with Firebase Authentication, student dashboard, admin dashboard, quiz management, results and the QCO AI Question Studio.

## AI Question Studio
See [AI_SETUP.md](AI_SETUP.md) for the one-time Firebase AI Logic and App Check configuration required to activate automatic AI question generation.

## Technology
- HTML, CSS and JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase AI Logic (Gemini Developer API)
- GitHub Pages

## Important
AI-generated questions should be reviewed by QCO administrators before formal competitions. Quiz content and private answer keys are stored separately.
